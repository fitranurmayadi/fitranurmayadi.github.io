# Fitra Nurmayadi — Official Technical Portfolio

🚀 **Live Site**: [https://fitranurmayadi.github.io](https://fitranurmayadi.github.io)

Personal engineering portfolio of **Fitra Nurmayadi** showcasing research and engineering implementations across:
- **Edge AI & Hardware Benchmarking** (YOLO11-OBB SBC/NPU Benchmark Suite across Raspberry Pi 5, Hailo-8L 13 TOPS, Jetson Orin Nano, Khadas Edge 2; ESP32 Micro-LM 1.84M on-chip LLM; TinyML).
- **Robotics & Autonomous Control** (3-DOF Robotic Arm with YOLOv11 Computer Vision Sorting, Two-Wheeled Self-Balancing Robot, Line Follower with On-Track EEPROM PID Tuning, Wi-Fi Combat Sumo Robot).
- **Reinforcement Learning & Simulation** (RocketLander3D 6-DOF Falcon 9 VTVL Simulator with Gymnasium & PyBullet, LunarLander3D).
- **Embedded Systems & IoT Hardware** (ideaSTEAM XB1 custom educational devboard & PCB design, EV powertrain telemetry, ESP32-C3 AC mains power meter).

---

## 🛠 Tech Stack & Architecture

- **Core**: Vanilla HTML5 semantic layout, modern Vanilla CSS3, ES6 JavaScript.
- **Typography**: Inter (primary sans-serif) and JetBrains Mono (hardware tags, specs, metrics).
- **Zero Bloat**: No heavy frameworks, no external runtime dependencies, sub-millisecond client-side filtering.
- **Theme**: High-contrast dark mode default with instant light mode toggle (persisted via `localStorage`).
- **Hosting**: Deployed statically on GitHub Pages with `.nojekyll` enabled.
